# 📈 Tesla (TSLA) Stock Price Prediction using SimpleRNN and LSTM

An end-to-end deep learning project that predicts Tesla's stock closing price **1, 5, and 10
trading days ahead**, comparing **SimpleRNN** and **LSTM** architectures, with hyperparameter
tuning, full evaluation, and an interactive **Streamlit** dashboard.

---

## 🚀 Features

- **Data Cleaning** — duplicate removal, missing value handling via forward/backward fill
  (appropriate for time-series data).
- **Exploratory Data Analysis** — 15+ visualizations including price trends, moving averages,
  correlation heatmaps, candlestick charts, and rolling volatility (Matplotlib, Seaborn, Plotly).
- **Feature Engineering** — moving averages (MA20/50/100), daily returns, rolling volatility,
  and lag features.
- **Deep Learning Models** — SimpleRNN and LSTM, each predicting **1-day, 5-day, and 10-day**
  ahead closing prices via a multi-output architecture.
- **Hyperparameter Tuning** — Keras Tuner `RandomSearch` over units, dropout rate, and
  learning rate.
- **Model Evaluation** — RMSE, MSE, MAE, MAPE, and R² across all models and horizons, with
  side-by-side comparison tables and plots.
- **Future Forecasting** — generates 1/5/10-day-ahead price forecasts from the most recent data.
- **Streamlit App** — interactive dashboard with Home, Dataset Overview, EDA, Model Performance,
  and Forecasting pages.

## 🗂️ Dataset

The dataset must follow the standard OHLCV schema:

| Column | Description |
|---|---|
| `Date` | Trading date |
| `Open` | Opening price |
| `High` | Day's highest price |
| `Low` | Day's lowest price |
| `Close` | Closing price (primary prediction target) |
| `Adj Close` | Dividend/split-adjusted closing price |
| `Volume` | Shares traded |

Place your `TSLA.csv` file in the `data/` folder. If you don't have the original Kaggle/Yahoo
Finance Tesla dataset, the pipeline includes a synthetic-but-realistic sample dataset so the
notebook runs end-to-end out of the box — simply replace it with real data for your final
submission (no code changes required, the schema matches).

## 📓 Usage

### 1. Run the Jupyter Notebook
This trains both models, runs hyperparameter tuning, evaluates performance, and saves all
artifacts (`models/*.keras`, `scaler.pkl`, `metadata.pkl`, `streamlit_assets.pkl`,
`data/TSLA_processed.csv`) required by the Streamlit app.

```bash
jupyter notebook notebooks/Tesla_Stock_Price_Prediction.ipynb
```

Run all cells from top to bottom (**Run All**). On a CPU, the full run takes a few minutes with
the default reduced epoch/trial counts. For a final submission, increase `EPOCHS`,
`MAX_TRIALS`, and `TUNER_EPOCHS` in the notebook for stronger results.

### 2. Launch the Streamlit App
```bash
streamlit run app/app.py
```

Then open the URL shown in the terminal (typically `http://localhost:8501`).

**App Pages:**
- **Home** — project overview and latest price snapshot.
- **Dataset Overview** — shape, head/tail, dtypes, statistical summary.
- **EDA** — interactive price trends, distributions, correlation heatmap, moving averages,
  and volatility.
- **Model Performance** — comparison table and charts for SimpleRNN, LSTM, and Tuned LSTM
  across RMSE/MSE/MAE/MAPE/R² and all forecast horizons.
- **Forecasting** — generates 1/5/10-day-ahead closing price predictions using the
  best-performing model.

## ☁️ Deployment

This project uses **relative paths only** and is ready to deploy as-is.

### Streamlit Community Cloud
1. Push this repository to GitHub.
2. Go to [share.streamlit.io](https://share.streamlit.io) and create a new app.
3. Set the **main file path** to `app/app.py`.
4. Streamlit Cloud will automatically install dependencies from `requirements.txt`.

### Render
1. Create a new **Web Service** from your GitHub repo.
2. **Build Command:** `pip install -r requirements.txt`
3. **Start Command:**
   ```bash
   streamlit run app/app.py --server.port $PORT --server.address 0.0.0.0
   ```

### Railway
1. Create a new project from your GitHub repo.
2. Railway auto-detects Python; ensure `requirements.txt` is at the project root.
3. Set the start command:
   ```bash
   streamlit run app/app.py --server.port $PORT --server.address 0.0.0.0
   ```

> ⚠️ Make sure `models/`, `data/`, and `app/` are all committed to the repo (model `.keras`
> files can be a few MB each — use Git LFS if your hosting provider has strict size limits).
